# Docs

This folder now holds the submission-facing materials for the Group 1 DIU Assistant track.

Recommended contents:

- `architecture.md`: short system architecture diagram and component notes
- `deployment.md`: local and permanent backend deployment notes
- `observability.md`: logging design and the review routine for slow/error cases
- `project_report_outline.md`: report scaffold aligned to the software submission
- `submission_checklist.md`: final cleanup and handoff checklist before GitHub/course submission

The runtime app does not depend on these files, so they can be edited freely without changing the product itself.
